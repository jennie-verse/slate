# slate — 무한 캔버스 그리기 앱

iPad와 iPhone에서 Apple Pencil이나 손가락으로 도형·화살표·글씨를 자유롭게 배치하는 개인용 무한 캔버스입니다. 기기 안에 저장되고, 인터넷 없이 동작하며, 그린 것은 어디로도 나가지 않습니다.

배포 주소: `https://jennie-verse.github.io/slate/`

---

## grove와의 경계

> **구조가 있으면 grove, 자유로우면 slate.**
> 항목 사이에 부모-자식 관계가 있고 나중에 접었다 펴고 싶다면 grove.
> 위치와 모양을 손으로 정하고 싶고 화살표를 아무 데나 긋고 싶다면 slate.

두 앱은 기능을 서로 베끼지 않습니다. slate에 트리 자동 배치를 넣지 않고, grove에 자유 드로잉을 넣지 않습니다.

## 지금 할 수 있는 것 (1 · 2단계)

- **도구 11가지** — 선택(Select) · 이동(Pan) · 사각형(Rectangle) · 마름모(Diamond) · 타원(Ellipse) · 화살표(Arrow) · 선(Line) · 자유 곡선(Draw) · 텍스트(Text) · 이미지(Image) · 지우개(Eraser)
- 무한 캔버스, 두 손가락 이동, 핀치 확대·축소
- Apple Pencil 필압, 손바닥 무시
- 선택 · 이동 · 크기 조절 · 회전 · 복제 · 삭제 · 다중 선택
- 실행 취소(Undo) / 다시 실행(Redo)
- **보드를 여러 개** 만들어 목록으로 관리 (원본 excalidraw.com에는 없는 기능)
- 자동 저장, 캔버스 배경색 변경, 다크 모드
- 내보내기 — PNG · SVG · `.excalidraw`
- 가져오기 — `.excalidraw` (excalidraw.com에서 만든 파일)
- 전체 백업 / 복원

### 2단계에서 더해진 것 — 다이어그램

- **화살표를 도형에 붙이기** — 도형을 옮기거나 크기를 바꿔도 화살표가 따라옵니다
- **도형 안 글자** — 자동 줄바꿈, 한글은 글자 단위로 나뉩니다
- 그룹 / 그룹 해제 · 잠금
- 정렬 · 균등 분배 · 좌우상하 뒤집기
- 격자 표시와 스냅 · 객체 정렬 보조선
- 복사 / 붙여넣기 · 스타일만 복사 · 클립보드로 PNG·SVG
- **사진 넣기** (큰 사진은 자동으로 줄여서 저장)
- 캔버스 안 글자 찾기 · 요소에 링크 붙이기
- 길게 눌러 나오는 메뉴
- 자주 쓰는 도형 저장 (`.excalidrawlib`)
- 윤곽형 화살촉 3종 · 전체 맞춤 / 선택 영역 맞춤 · 하드웨어 키보드 단축키 전체

## 아직 없는 것 (3단계 예정)

프레임 · 직각 화살표 · 선/화살표 점 편집 · 다각형 · 이미지 자르기 · 올가미 선택 · 레이저 포인터 · 명령 팔레트 · Zen 모드 · PNG·SVG에 장면 데이터 심기

## 만들지 않는 것

실시간 공동 편집 · 공유 링크 · AI 기능 · YouTube 등 웹 임베드.
전부 서버나 외부 API가 필요해서, 이 앱의 전제(오프라인 · 외부 통신 없음)와 정면으로 충돌합니다.

## 처음 한 번만 하면 되는 일

**Safari에서 위 주소를 연 다음, 그리기를 시작하기 전에 홈 화면에 추가하세요.**

`공유(Share) → 홈 화면에 추가(Add to Home Screen)`

iOS는 **홈 화면 앱과 Safari의 저장 공간을 분리**합니다. Safari에서 먼저 그린 보드는 홈 화면 앱에서 보이지 않습니다. 고장이 아니라 iOS의 동작이며, 처음부터 홈 화면 앱으로 시작하면 겪지 않습니다.

자세한 사용법은 [USER-GUIDE-KO.md](./USER-GUIDE-KO.md)에 있습니다.

## 화면 언어

앱 화면은 영문입니다. 캔버스에 쓰는 글, 보드 이름, 내보내는 파일 이름에는 **한글이 정상 동작**합니다.

손글씨 글꼴(Virgil)에는 한글이 없어서, 한 텍스트에 영문과 한글이 섞이면 **영문은 손글씨체, 한글은 시스템 고딕체**로 보입니다. 의도된 동작이며, 한글 위주 텍스트는 그 요소의 글꼴을 `Normal`로 바꾸면 통일됩니다.

## 데이터

- 저장 위치: 기기 안 IndexedDB. 서버로 아무것도 보내지 않습니다.
- 저장 상태는 화면 오른쪽 위에 `Saved` / `Saving…` / `Not saved`로 표시됩니다.
- 저장할 때마다 **직전 판 1개**를 따로 보관합니다. 설정(Settings)에서 되돌릴 수 있습니다.
- 기기를 잃으면 그림도 사라집니다. **정기적으로 백업하세요** — [BACKUP-RESTORE-KO.md](./BACKUP-RESTORE-KO.md)
