## 2. 현재 기능 (한 번에 정리)

- **드로잉/보드**: 펜·지우개·도형·텍스트, 화살표 바인딩, 실행취소/재실행, 제스처 중 삭제·이동 명령 차단, 컨텍스트 메뉴·패널 삭제 모두 동일 경로(`deleteSelection`)로 처리
- **보드 전환**: 전환 시 진행 중이던 제스처는 저장 전에 취소되고, 대기 중인 쓰기는 (되살아날 위험이 없는 한) 플러시됨. 보드 쓰기 앞의 모든 `await`가 보드 상태를 다시 확인
- **동기화**: `history.run()`을 따라가는 동기화는 스택이 아니라 병합. 가져오기(import)가 다른 사람의 삭제를 되살리지 않음
- **입력**: 키보드로 화살표 이동 시 바인딩된 도형도 함께 이동, 두 번 탭 감지가 일반 탭이 아닌 제스처는 무시, IME 조합 중 편집기가 커밋돼도 안전
- **저널(journal)**: 활동 기록과 세션 기록을 별도 로컬 저장소에 남김

## 3. 새로 추가됨 — 첫 실행 초기화 (`src/fresh-start.js`)

이번 릴리즈에서 앱을 "첫 배포처럼" 보이게 하기 위해 1회성 초기화 모듈을 추가했습니다.

- `APP_BUILD` (`2026.09.05-release`) 기준으로 게이트되어 **한 번만** 실행됨
- 지워지는 것: slate의 IndexedDB(`slate` DB 전체 — 보드/콘텐츠/설정)와 slate 전용 localStorage 9개 키
  - `slate:fontStep`, `slate:theme`, `slate:panelCollapsed`, `slate:installHintSeen`
  - `slate.journalEnabled.v1`, `slate.journalActivity.v1`, `slate.journalSessions.v1`
  - `slate.syncContextId`, `slate.syncContextLabel`
- **건드리지 않는 것**: `sync.token.v1` (오리진 전체가 공유하는 로그인 토큰이라 지우면 다른 앱까지 로그아웃됨) 및 `../shared/v1`, `../shared/v2` 아래 모든 것
- `app.js`의 첫 import로 실행되어, `settings.js`가 자기 키를 읽기 전에 localStorage 정리가 끝나도록 순서를 보장
- IndexedDB 삭제와 이후의 `store.open()`이 경합하지 않도록 `ready` 프라미스로 순서를 강제
