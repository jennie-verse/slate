# slate 사용 안내

---

## 1. 설치

1. iPhone 또는 iPad에서 **Safari**로 `https://jennie-verse.github.io/slate/` 를 엽니다.
2. 화면 아래(iPhone) 또는 위(iPad)의 **공유(Share)** 버튼을 누릅니다.
3. **홈 화면에 추가(Add to Home Screen)** 를 고릅니다.
4. 오른쪽 위 **추가(Add)** 를 누릅니다.
5. 홈 화면에 생긴 아이콘으로 앱을 엽니다.

> **그리기 전에 이 단계를 먼저 하세요.**
> iOS는 홈 화면 앱과 Safari의 저장 공간을 나눕니다. Safari에서 먼저 그리면 그 보드는 홈 화면 앱에서 보이지 않습니다. 옮기려면 Safari에서 백업을 내보낸 뒤 홈 화면 앱에서 복원해야 합니다.

---

## 2. 화면 구성

기기와 방향에 따라 배치가 바뀝니다. **도구와 설정은 그대로 유지**되므로 기기를 돌려도 다시 고를 필요가 없습니다.

| 기기 | 배치 |
|---|---|
| iPad 가로 | 도구는 **왼쪽 세로 레일**, 속성은 **오른쪽 접이식 패널** |
| iPhone(가로·세로), iPad 세로 | 도구는 **화면 아래 막대**, 속성은 그 위 **시트** |

- **왼쪽 위**: 메뉴(≡) · 보드 이름 · 저장 상태
- **오른쪽 위**: 실행 취소(Undo) / 다시 실행(Redo) · 확대·축소 · 내용으로 돌아가기
  (iPhone에서는 자리가 좁아 확대·축소 버튼과 되돌아가기가 메뉴 안으로 들어갑니다)

---

## 3. 그리기

### 도구

| 도구 | 하는 일 | 단축키 |
|---|---|---|
| Select | 고르기·옮기기·크기 조절·회전 | V 또는 1 |
| Pan | 손가락 하나로 화면 밀기 | H |
| Rectangle | 사각형 | R 또는 2 |
| Diamond | 마름모 | D 또는 3 |
| Ellipse | 타원 | O 또는 4 |
| Arrow | 화살표 | A 또는 5 |
| Line | 선 | L 또는 6 |
| Draw | 자유 곡선 | P 또는 7 |
| Text | 글자 | T 또는 8 |
| Eraser | 지우개 | E 또는 0 |

단축키는 iPad에 하드웨어 키보드를 연결했을 때 쓸 수 있습니다.

### 조작

- **두 손가락**으로 밀면 화면 이동, 벌리거나 오므리면 확대·축소
- **Apple Pencil**은 필압이 반영됩니다. 펜으로 그리는 동안 손바닥이 화면에 닿아도 선이 그어지지 않습니다
- **Shift**를 누른 채 그리면 정사각형·정원, 화살표와 선은 15°씩 각도가 맞습니다
- 지우개는 **문지르듯 드래그**하면 지나간 요소가 지워집니다. 한 번의 Undo로 전부 되돌아옵니다

### 고르고 바꾸기

1. **Select** 도구로 요소를 누릅니다
2. 파선 테두리와 **8개 손잡이**가 나타납니다
3. 모서리·변 손잡이로 크기를, 위쪽에 떨어져 있는 동그란 손잡이로 회전을 조절합니다
4. 빈 곳에서 드래그하면 사각형 범위 안의 요소가 한꺼번에 선택됩니다
5. **Shift**를 누른 채 누르면 선택에 더하거나 뺍니다

> 얇은 선은 손가락으로도 잡히도록 판정 범위를 넉넉히 두었습니다. Apple Pencil은 더 정밀하게 잡습니다.

### 글자 쓰기

1. **Text** 도구를 고르고 캔버스를 누릅니다
2. 바로 입력합니다. **한글 입력도 정상 동작**합니다
3. 마치려면 **Esc**, 또는 캔버스의 다른 곳을 누릅니다
4. 이미 있는 글자를 고치려면 Text 도구로 그 글자를 누르거나, Select로 고른 뒤 **Enter**

한 글자 요소에 영문과 한글이 섞이면 영문은 손글씨체, 한글은 시스템 고딕으로 보입니다. 통일하려면 그 요소를 고른 뒤 속성 패널에서 **Font → Normal**로 바꿉니다.

## 4. 속성 바꾸기

아무것도 선택하지 않은 상태에서 바꾸면 **다음에 그릴 것**의 기본값이 되고, 선택한 상태에서 바꾸면 **선택한 요소**가 바뀝니다.

| 항목 | 값 |
|---|---|
| Stroke | 선 색 5가지 + 직접 고르기 |
| Background | 채움 색 (투명 + 4가지) + 직접 고르기 |
| Fill | Hachure(빗금) / Cross(교차) / Solid(채움) / Zigzag(지그재그) |
| Stroke width | Thin / Bold / Extra bold |
| Stroke style | Solid / Dashed / Dotted |
| Sloppiness | Architect(반듯) / Artist(보통) / Cartoonist(많이 삐뚤) |
| Edges | Sharp(각진) / Round(둥근) |
| Opacity | 10~100% |
| Font size | S / M / L / XL |
| Font | Hand-drawn / Normal / Code |
| Align | Left / Center / Right |
| Arrow type | Sharp(꺾인) / Curved(곡선) |
| Arrowhead | 시작·끝 각각 None / Arrow / Bar / Dot / Triangle / Diamond |
| Layer | Back / Down / Up / Front (앞뒤 순서) |

## 5. 보드 관리

**메뉴(≡) → Boards**

- 보드를 눌러 엽니다
- 각 보드에 **요소 개수 · 용량 · 마지막 수정 시각**이 표시됩니다
- 오른쪽 × 로 지웁니다. 목록에서 사라지지만 백업에는 남아 복원할 수 있습니다
- 이름을 바꾸려면 화면 왼쪽 위의 **보드 이름을 누릅니다**
- 새 보드는 **메뉴 → New board**

## 6. 내보내기

**메뉴(≡) → Export image**

| 형식 | 쓸 곳 |
|---|---|
| **PNG** | 사진처럼 붙여 넣기. 배율 1x·2x·3x |
| **SVG** | 인쇄, 확대해도 안 깨짐 |

- `Include background` — 캔버스 배경색을 함께 넣을지
- `Export in dark colours` — 어두운 배경용으로 색을 바꿔 내보내기
- `Embed handwriting font (SVG)` — **켜 두는 것을 권합니다.** 글꼴이 없는 기기에서도 손글씨체가 유지됩니다. 파일이 약 60KB 커집니다

**보드가 아주 크면 PNG 배율이 자동으로 낮아집니다.** 기기가 감당할 수 있는 크기를 앱이 직접 재서 판단하며, 그 사실을 화면에 알려 줍니다. 배율 1에서도 넘칠 만큼 크면 **SVG로 내보내세요** — SVG에는 이 제한이 없습니다.

**메뉴 → Export .excalidraw** 로 내보낸 파일은 excalidraw.com에서 그대로 열립니다.
**메뉴 → Import .excalidraw** 로 excalidraw.com에서 만든 파일을 가져올 수 있습니다.

> 아직 지원하지 않는 요소(프레임 등)가 든 파일을 가져오면 **회색 자리표시자**로 표시되고 "여기서는 편집할 수 없음"이라고 나옵니다. 그 정보는 지워지지 않고 그대로 보관되어, 다시 내보내면 원래대로 들어갑니다. 이미지가 든 파일도 마찬가지로 사진 데이터를 그대로 안고 갑니다.

## 7. 설정

**메뉴(≡) → Settings**

- **App text size** — 앱 글자 크기 6단계(6·8·10·12·14·17px). 기본 12px
  - 글자만 작아지고 **버튼 크기는 그대로**입니다
  - 캔버스에 그린 글자는 여기가 아니라 요소 속성(S/M/L/XL)이고 확대·축소를 따릅니다
- **Theme** — Auto / Light / Dark
- **Build** — 지금 이 기기에서 실행 중인 버전. 업데이트가 반영됐는지 확인할 때 봅니다
- **Recover previous version of this board** — 직전에 저장된 판으로 되돌립니다

---

## 8. 알아두면 좋은 것

- **자동 저장**됩니다. 손을 멈추면 잠시 뒤 저장되고, 앱을 나갈 때도 강제로 저장합니다
- 저장 상태가 **`Not saved`** 로 빨갛게 남아 있으면 저장이 실패한 것입니다. **바로 백업을 내보내세요**
- 그림이 어디 있는지 모르겠으면 **내용으로 돌아가기**(오른쪽 위 네모 아이콘, iPhone은 메뉴 → Scroll back to content)
- **메뉴 → Reset this canvas** 는 그 보드의 요소를 전부 지웁니다. 확인을 거치고, 바로 Undo로 되돌릴 수 있습니다
