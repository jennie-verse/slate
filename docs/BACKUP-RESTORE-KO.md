# 백업과 복원

그림은 **이 기기 안에만** 있습니다. 서버에 사본이 없습니다. 기기를 잃거나 초기화하면 백업 없이는 되찾을 수 없습니다.

---

## 1. 전체 백업 (가장 중요)

**메뉴(≡) → Backup all boards**

1. 모든 보드와 설정이 든 JSON 파일 하나가 만들어집니다
2. iOS 공유 시트(Share Sheet)가 열립니다
3. **파일에 저장(Save to Files)** → **iCloud Drive** 를 고르면 다른 기기에서도 꺼내 쓸 수 있습니다

파일 이름 예: `slate-backup-2026-08-13.json`

> **권장 주기**: 중요한 그림을 그린 날, 그리고 최소 한 달에 한 번.
> 저장 상태가 `Not saved`로 남아 있을 때는 **즉시** 백업하세요.

## 2. 복원

**메뉴(≡) → Restore from backup** → 백업 JSON 파일 선택

두 가지를 고를 수 있습니다.

| 선택 | 결과 |
|---|---|
| **Replace all** | 이 기기의 보드를 전부 지우고 백업 내용으로 바꿉니다 |
| **Cancel**(합치기) | 지금 보드를 그대로 두고 백업 보드를 **추가**합니다 |

- 백업이 아닌 파일이나 형식이 깨진 파일은 **읽기 전에 거부**합니다
- **더 새로운 버전의 slate로 만든 백업은 읽지 않고 경고만 합니다.** 반쯤 읽어 데이터를 망가뜨리지 않기 위해서입니다. 이 경우 앱을 먼저 업데이트하세요

---

## 3. 그림 파일로 내보내기

백업(JSON)은 앱으로 되돌리기 위한 것이고, 아래는 다른 곳에 쓰기 위한 것입니다.

| 메뉴 | 형식 | 특징 |
|---|---|---|
| Export image → Export PNG | `.png` | 어디에나 붙습니다. 편집은 안 됩니다 |
| Export image → Export SVG | `.svg` | 확대해도 안 깨집니다. 인쇄에 좋습니다 |
| Export .excalidraw | `.excalidraw` | **excalidraw.com에서 그대로 열립니다.** 편집 가능 |

`.excalidraw`는 보드 하나만 담습니다. 여러 보드를 한꺼번에 옮기려면 전체 백업을 쓰세요.

한글이 든 보드 이름은 파일 이름에 그대로 들어갑니다 (예: `slate-회의노트-2026-08-13.png`).

---

## 4. 자동으로 남는 안전장치

의식하지 않아도 동작하는 것들입니다.

- **직전 판 보관** — 저장할 때마다 바로 이전 내용을 따로 한 부 남깁니다. 슬롯은 하나이고 더 오래된 것은 버립니다.
  되돌리려면 **설정(Settings) → Recover previous version of this board**
- **보드 삭제는 표시만** — 목록에서 지운 보드는 곧바로 사라지지 않고 삭제 표시만 됩니다. 백업 파일에는 남아 있어 복원할 수 있습니다
- **저장 실패를 숨기지 않음** — 용량 초과나 저장소 오류가 나면 `Not saved`가 남고 백업하라는 안내가 뜹니다

---

## 5. 기기를 바꿀 때

1. 옛 기기에서 **Backup all boards** → iCloud Drive에 저장
2. 새 기기 Safari에서 slate를 열고 **홈 화면에 추가**
3. 홈 화면 앱을 열고 **Restore from backup** → iCloud Drive의 파일 선택 → **Replace all**

> 2번을 건너뛰고 Safari에서 복원하면, 나중에 홈 화면 앱에서 그 보드가 보이지 않습니다. iOS가 두 저장 공간을 나누기 때문입니다.

---

## 6. 기기 사이에서 이어 그리기

**1·2단계에는 자동 동기화가 없습니다.** iPhone에서 그리던 것을 iPad에서 이어 그리려면 지금은 `.excalidraw`나 백업 파일을 거쳐야 합니다.

기기 간 이어쓰기는 4단계 계획으로 잡혀 있고, 보드 하나가 실제로 몇 KB인지 재고 나서 착수합니다. 그래서 보드 목록에 용량이 표시됩니다 — 그 숫자가 쌓이는 것이 착수 조건입니다.
